# Petri Eden

Petri Eden is a deterministic native artificial-life laboratory: design species, start an ecosystem, intervene during a run, and inspect how ecology and inherited neural controllers shape descendants.

## Scope

### Covers

- Petri Eden's product, domain, architecture, evidence, and roadmap boundaries.
- Deterministic artificial-life simulation and ecology-first neuroevolution.
- Native inspection surfaces for populations, materials, lineage, perception, neural decisions, and run provenance.
- Operational species as reproducible lineage/genome clusters.
- V2 plasticity and Baldwin-effect research as draft work.
- V3 embodied agents, communication, and cultural inheritance as a brainstorm.
- Honest separation between implemented code, committed plans, and speculative research.

### Not Covered

- General reinforcement-learning implementation guidance.
- Claims that Petri Eden proves open-ended evolution, intelligence, communication, or culture.
- Private repository URLs, machine paths, credentials, unpublished artifacts, or release binaries.
- V2/V3 ideas presented as shipped v1 capabilities.
- Generic LLM-agent systems unrelated to embodied evolutionary experiments.

### Current As

2026-07-24. Native v1 work is implemented through deterministic simulation, spatial perception, ecology, evolution/mutation, and time control. Ecosystem telemetry is the active frontier. Species recognition, neural-decision inspection, interventions, persistence, endurance, scale, onboarding, packaging, and release certification remain later planned epics. One predator-viability ecology mechanism is awaiting a human product decision.
