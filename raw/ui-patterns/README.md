# UI Patterns

> Product and persuasive interface pattern catalog for agents, compiled as a provenance-forward navigation layer over [ui-patterns.com](https://ui-patterns.com/patterns).

## Scope

### Covers

The `ui-patterns` namespace covers the public UI Patterns pattern catalog structure: pattern titles, source URLs, UI/persuasive taxonomy, section availability, example counts, provenance, copyright boundary, and agent-facing retrieval guidance for product/design review.

### Not Covered

This namespace does not republish full source pattern bodies, screenshots, comments, paid card-deck content, or commercial-clean training data. For exact wording and examples, retrieve the original source page and quote only bounded snippets when necessary.
